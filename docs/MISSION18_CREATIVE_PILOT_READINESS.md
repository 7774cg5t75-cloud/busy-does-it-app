## Proposed exact experiment

One owner-reviewed fictional **Quiet Light Studio**, with no photography, credentials or customer records. Compare its existing deterministic recommendation with one actual model proposal. Both start from identical approved words, branding, routes, section identities and destinations and use the original renderer. Inspect complete phone/desktop pages using opaque labels; retain invalid, unchanged and inferior results. Choose no automatic winner. One result cannot prove reliable model superiority or ten-page commercial economics.

Proposed provider/model: **OpenAI Responses / `gpt-6.1-sol`**, standard global processing. Maximum one inference, **4,000 input tokens, 1,000 total output tokens and £0.10 all-in admitted financial exposure**. No tools, retries, fallback, automatic account save, publication or customer action. `max_output_tokens` includes the model's output allowance; truncation/refusal is a retained failed experiment, not permission to retry.

The new `busy.website-design-intelligence.v1` schema can propose coordinated composition measures and exact current-section permutations across existing pages. It cannot write business facts, routes, photographs, arbitrary CSS/HTML/JavaScript, prices or actions. Every operation still requires the original whole-site source check, sealed owner review and Website Studio authority. Its new provider wire projection is a pure function with **no network, credential, activation or spending port**. A provider response remains unverified until original service-only usage settlement/readback proves its receipt.
