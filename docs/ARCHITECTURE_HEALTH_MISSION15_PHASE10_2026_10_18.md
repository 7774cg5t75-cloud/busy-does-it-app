2. **Selected context had incomplete recovery — corrected.** Website typography menu state was not scoped to element/type and could reference a nonexistent category after a paragraph-to-heading selection change. Menu state and old callbacks now bind exact source/selection. App selection/image/instruction drafts likewise reject stale source, unknown inherited keys and ambiguous unsupported requests. Native selected inputs remain preview-only until original Studio approval/CAS; unknown saves retain the earlier session barrier.
3. **Duplicate gallery presentation/projection — reduced.** A single pure public-gallery rule now supplies marketplace and guest/native projection copies, with byte parity tested. It preserves the prior native 15-image contract and approval flags while correcting marketplace's 12-image limit. Caption surfaces/colours/typography now use existing Brand DNA tokens; explicit solid-background contrast is calculated. No new media service, schema, source-of-truth store or AI engine. Copies remain necessary for isolated Edge packaging; parity tests must remain in the regression selection.
4. **Legacy tests depended on source spelling — corrected where encountered.** Two inherited voice/order assertions no longer matched the refactored original comparison and mutation gate even at the starting checkpoint. Actual component/renderer and move-adapter execution now tests equivalent behaviour with stale-revision/receipt refusal. Other historical tests still contain source assertions; replace them when implementation changes expose brittleness, retaining behaviour/security evidence.
5. **Owner UI has overlapping old/new entry points — deferred carefully.** New contextual controls reuse the existing interpretation and Studio transaction systems, but older full editors still supply capabilities not covered by the finite selected subset. Rationalise presentation after targeted owner/device acceptance rather than deleting functionality or inventing another engine. AppVisualSelection grows 5,670 → 6,745 bytes; selected image/instruction components own bounded UI responsibilities. appContextInstruction grows 2,574 → 6,756 bytes; keep future vocabulary in this existing interpreter and catalogue, not parallel parsers.
6. **Cross-destination and runtime evidence remains bounded.** Signed-in app_detail returns a live version config; native uses a minimised projection. This phase aligns gallery rendering, not all public wire fields or endpoint contracts. Review remaining destination differences before release. Existing exact published-version checks, approved media, tenant/owner gates and idempotency tests pass offline; no hosted RLS/actual customer data was accessed. Root runtime lock/install, Expo/device, Deno and sandbox-compatible browser acceptance remain separate.
