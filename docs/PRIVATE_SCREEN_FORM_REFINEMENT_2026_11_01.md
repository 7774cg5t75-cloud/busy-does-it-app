## What now works

The original App goal editor and private function library now lead into a private screen library. Owners can choose an eligible accepted calculation/form, place it on an enabled original About, Services or Contact screen, inspect the actual private preview, deliberately approve/save, independently read back and reopen the exact placement. Local Calculate/Check and reset controls perform finite evaluation only; there is no Send, Book, Order or Pay action.

Placement removal preserves the underlying artifact. Previous placements can be prepared again for new approval; they are not silently restored as current authority. Disabled or superseded artifacts do not continue running through old bindings. Changed App revisions require renewed review. Unsaved local test values survive return navigation within the same exact private context, not account switching. Test values and unsaved review tickets are session state, not a new durable customer-data store.

The form editor supports adding within the existing eight-field bound, removing/reordering, numeric/text/fixed-choice/boolean types, labels, required/optional, permitted options, numeric limits/defaults/units, text limits, and supported earlier-choice/boolean conditional relevance. Removal/type changes that break calculation dependencies or conditions are refused. New fields, changed assumptions and regenerated acceptance examples require fresh review; immutable accepted versions are never edited in place. Bounded local Undo restores the previous draft and test values, not server authority.

Finite natural corrections include adding a postcode question, moving guest count first, removing an exact question, explicit allowance percentages, supported conditional questions and selecting Contact placement. Unsupported or ambiguous requests are explained rather than guessed. This remains finite recognition, not unrestricted language intelligence. Per-field arbitrary instruction/validation scripts are not supported.

An eligible reviewed calculation can be copied into a new form draft after exact integrity/ownership checks. This copies reviewed finite inputs/rules into independently reviewed new form bytes; it is not a live permission-bearing link. Later calculation changes do not silently alter an accepted form. The source candidate/context is rechecked before the asynchronous draft handoff so newer owner edits are preserved.
