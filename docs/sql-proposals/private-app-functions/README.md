## Storage and permissions

`busy_app_function_private` contains settings, scoped current heads and immutable versions. Each version records exact original owner/business/App, App source revision, full validated finite rule schema, reviewed examples, actor/time, request nonce, canonical PostgreSQL JSON text and its SHA-256. SQL independently validates supported graphs and expected examples using bounded numeric arithmetic. The original JS finite interpreter also validates independently before admission and after reopening. The digest detects altered bytes; it is not a signature or substitute for trusted identity.

No anonymous, authenticated or service-role table/schema access. RLS is enabled without client policies. The sole public-schema RPC is service-only, with protected search path; the authenticated original Mini App gateway derives actor/business/App from trusted identity and current owner membership. Membership and original App locks protect meaningful transactions. App writes do not share this artifact storage and are not silently performed by artifact acceptance.

A series permits eight functions per App and sixteen immutable versions each. Save requires exact App revision, current head version/revision, a new request nonce, exact source scope and validated examples. Repeated nonces are refused for inspection, never replayed. Revision creates a new version; older versions remain historical and ineligible. Disable closes the current series to previews. A separately reviewed successor may supersede it. No deletion/retention erasure process is activated by this proposal.
