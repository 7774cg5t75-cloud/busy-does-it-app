Missing Deno, denied environment access, absent/malformed credentials fail generically before provider dispatch and release the undispatched reservation through the original controller.

The Deno-specific factory overrides any supplied credential-reader property; only trusted future server bootstrap may construct the dependency set. Credential presence does not enable policy or prove key permissions/model availability. The key stays in the server call stack and Authorization header of the existing fixed-endpoint transport; it is absent from proposal input, request body, hashes, receipts, responses and logs. Exceptions are not reflected to callers. Never log request headers, fetch options, the reader's return value or provider transport errors containing credentials.
