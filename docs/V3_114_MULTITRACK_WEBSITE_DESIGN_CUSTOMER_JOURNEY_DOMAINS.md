# V3.114 Multi-track sweep — measurable website reviews + simple editor + domain trust

## Track 1: customer simplicity
The Website Builder now explains the single next step derived from existing business readiness, a fresh hosted preview, explicit owner approval, and matching public website delivery proof. Choosing or buying a domain **does not block** building a website. Nothing is auto-published. Customers can now cycle between several relevant, named website designs from a one-tap action, rather than needing a specialist design prompt or being offered only the first alternative. Changes use the pre-existing private, undoable editor.

## Track 2: website review integrity
The actual shared visual review cycle now refuses to promote any proposed private design which introduces unassessed text contrast or reduces measured text inspection coverage, even when other accessibility counters hold steady. It still uses two real mobile/desktop screenshots and trusted measurements, owner-approved changes, saved business content, tenant boundaries, and paid-model reservation rules before any visual AI request. Offline browser CI measures before/after website alternatives, deliberately broken navigation, five different designs, phone sizes, desktop and keyboard accessibility.

The sweep **does not** deploy an autonomous live AI vision model or guarantee a designer-like aesthetic opinion. Production image analysis requires later approved credentials, billing and capture provider verification.

## Track 3: domain-management clarity and tenant privacy
Customers connecting their own domain now see plainly that DNS connection does not transfer domain ownership or handle registrar renewals; they should continue renewing their existing domain at their registrar. Domain buying remains explicitly unconnected. A BUSY-provided address remains optional until the public address is verified.

The purchase preview contract now removes an important possible data leak: registration/renewal pricing is only displayed after the entire future live quote passes business ownership, provider identity, freshness, currency, price arithmetic, renewal disclosure and terms checks. Cross-business, stale, missing or fictional quotes show no charges.

## QA and limits
New V3.114 tests cover independent tracks, alongside existing registrar and design regressions, iOS JavaScript compile, Playwright before/after quality and visual variety. The branch is development source only. No paid API, domain purchase, customer DNS change, production Edge deployment, live customer website publishing or signed native build occurs.

## Following sweeps
Finalize a genuinely live screenshot review engine with owner consent and usage limits, streamline website launch with one-page guided approvals, and pursue a registrar reseller sandbox only after vendor agreement and founder approval of any fees.
