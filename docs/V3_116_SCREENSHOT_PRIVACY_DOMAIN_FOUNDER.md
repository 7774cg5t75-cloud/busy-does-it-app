# V3.116 — Four parallel improvements

## Screenshots
The separately opt-in, strictly metered website vision reviewer now requires matching screenshot deployment and viewport proof headers from the configured trusted renderer, as well as actual PNG bytes, constrained dimensions, image MIME and non-cacheability. The Cloudflare browser worker emits this metadata for private hosted previews only. Offline Chromium QA compares authentic phone/desktop images and rejects CTA controls covered by another layer. This does NOT enable paid AI review or certify aesthetic quality. Customers still explicitly approve changes.

## Private learning
Most recent owner like/rejection per style now determines per-business design suggestions. Reused retry IDs must match the original user, business, revision and choice. No customer website content is stored. A pure, conservative seven-part checklist covers real migration validation, tenant isolation, replay, deletion and backups, retention/privacy notice, one-business canary and rollback. Passing this checklist does NOT deploy anything. Cross-business learning and model-weight retraining remain disabled.

## Domains
The website address chooser explains that the original BUSY address should be retained until the intended customer domain and actual live deployment have independent matching delivery evidence. The guide cannot purchase, transfer, switch DNS or auto-publish. No registrar API was activated.

## Founder reporting
The founder's read-only supplier inventory now contains a concise action list prioritising missing and older provider readings over recent readings. Provider traffic observations never become invoices or known pounds of costs. No new authorisations, provider queries, renewals, charges or upgrades were made.

## Operational boundary
This branch contains source and GitHub QA only, not a signed iPhone release. The V3.115 private learning migration remains unapplied to production. The screenshot renderer and AI provider still require approved external credentials and explicit funding. Production enablement must be reviewed separately after privacy/security checks.
